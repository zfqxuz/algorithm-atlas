01function Dijkstra(G, s, t):
02 for v in G.vertices:
03 dist[v] ← ∞; prev[v] ← null
04 dist[s] ← 0; PQ ← MinHeap((s, 0))
05 while PQ is not empty:
06 u ← PQ.extractMin()
07 if u = t: return rebuildPath(prev, t)
08 for (v, w) in G.adj[u]:
09 if v is finalized: continue
10 alt ← dist[u] + w
11 if alt < dist[v]:
12 dist[v] ← alt; prev[v] ← u
13 PQ.decreaseKey(v, alt)
14 return "unreachable"
01function BFS(G, s, t):
02 for v in G.vertices:
03 dist[v] ← ∞; prev[v] ← null
04 dist[s] ← 0; Q ← Queue([s])
05 while Q is not empty:
06 u ← Q.dequeue()
07 if u = t: return rebuildPath(prev, t)
08 for v in G.adj[u]:
09 if dist[v] ≠ ∞: continue
10 dist[v] ← dist[u] + 1
11 prev[v] ← u
12 Q.enqueue(v)
13 return "unreachable"
01function DFS(G, s, t):
02 for v in G.vertices:
03 dist[v] ← ∞; prev[v] ← null
04 seen ← {s}; dist[s] ← 0
05 stack ← [s]
06 while stack is not empty:
07 u ← stack.pop()
08 if u = t: return rebuildPath(prev, t)
09 for v in reverse(G.adj[u]):
10 if v in seen: continue
11 seen.add(v)
12 dist[v] ← dist[u] + 1; prev[v] ← u
13 stack.push(v)
14 return "unreachable"
01function Prim(G, root):
02 for v in G.vertices:
03 key[v] ← ∞; parent[v] ← null
04 key[root] ← 0; visited ← {}
05 while visited.size < |V|:
06 u ← minKey(unvisited)
07 if key[u] = ∞: break
08 visited.add(u); total += key[u]
09 for (v, w) in G.adj[u]:
10 if v not in visited and w < key[v]:
11 key[v] ← w; parent[v] ← u
12 return (visited, parent, total)
GREEDY INVARIANT

节点第一次从优先队列取出时，它的距离已经是最终最短距离。

时间复杂度 O((V+E) log V)
空间复杂度 O(V + E)

!边权必须非负，否则贪心前提不再成立。
