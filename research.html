TOPIC 01 · NETWORK FLOW

最大流 / 最小割

L4

一张有向网络、每条边有容量、源点要尽可能多地向汇点输送“流”。最大流问题问的是：在容量与流守恒约束下，最多能送多少？它的对偶答案是最小割。

MODEL流网络

有向图、非负容量、源点 s、汇点 t，流量在边上守恒。

ALGORITHM残量网络 + 增广路

沿残量容量大于 0 的路径推送流，直到不存在 s→t 路径。

THEOREMmax-flow = min-cut

最大流值恰好等于把 s 与 t 分开的最小容量割。

形式化

给定网络 G = (V, E)，容量 c(u,v) ≥ 0。流 f 满足容量约束 0 ≤ f(u,v) ≤ c(u,v)，除 s、t 外每个节点满足流守恒：流入量等于流出量。流的值 |f| 是源点净流出量。一个 s-t 割 (S, T) 满足 s ∈ S、t ∈ T，其容量是所有从 S 指向 T 的边容量之和。

0 ≤ f(u,v) ≤ c(u,v)
∑ᵥ f(v,u) = ∑ᵥ f(u,v) （u ≠ s,t）
max |f| = min c(S,T)

为什么增广路能工作

残量网络把“已经流过的流”也变成可撤销的容量：若 u→v 流了 x，则残量网络中存在一条 v→u、容量为 x 的反向边。只要还能找到 s→t 的残量路径，就能增加总流；当不存在增广路时，从 s 出发在残量网络中可达的点集 S 与其余点集 T 构成一个割，且该割的每条正向边都已饱和，于是当前流值等于割容量，达到最优。

Ford–Fulkerson 给出框架；若每轮只推 1 单位，复杂度 O(E·|f*|)，是伪多项式。Edmonds–Karp 用 BFS 选择最短增广路，复杂度 O(VE²)。Dinic 用分层图与阻塞流把上界改进到 O(V²E)，在单位容量网络上有更好的界。整数容量下每次增广至少推送 1 单位，因此从零流出发得到的最大流也是整数流。

研究视角

最大流是最优化与组合结构的交汇点：它可写成线性规划，其对偶正是最小割；二部图匹配、项目选择、图像分割、网络可靠性都能建模为流。整数容量下 Ford–Fulkerson 会得到整数流，这是全幺模性（total unimodularity）的一个具体体现。

常见误区：“最小割就是随便找一个最小的边集”。割必须把 s 与 t 分开，且容量按方向求和；另一个常见误区是以为 Ford–Fulkerson 一定多项式时间——朴素实现可能极慢，Edmonds–Karp 或 Dinic 才有多项式上界。

TOPIC 02 · OPTIMIZATION

线性规划与单纯形

L4

线性规划是在一个凸多面体上优化线性目标。它既是运筹学的语言，也是组合优化、近似算法与机器学习中反复出现的松弛工具。

标准形与几何

标准形通常写成：最大化 cᵀx，约束 Ax ≤ b、x ≥ 0。引入松弛变量后可以写成等式。可行域是一个凸多面体；如果最优值有限，至少有一个顶点是最优解。单纯形法沿可行域的边从一个顶点移动到相邻的更好顶点。

maximize cᵀx
subject to Ax ≤ b
x ≥ 0

对偶：minimize bᵀy s.t. Aᵀy ≥ c, y ≥ 0

单纯形与对偶

单纯形维护一个基（basis），把非基变量置零，解出基变量，再根据 reduced cost 判断是否还能改进；若可以，就做一次 pivot。弱对偶告诉我们任意可行原解与对偶解满足 cᵀx ≤ bᵀy；强对偶说，只要两者都可行且最优值有限，它们相等。互补松弛进一步刻画最优解中哪些约束是紧的。

单纯形的最坏情况可以是指数级（Klee–Minty 多面体），但实践中通常很快；Bland 规则按最小下标入基/出基，可以排除循环。椭球法与内点法给出了多项式时间保证。线性规划处于 P 中，而整数线性规划是 NP-hard。强对偶也可由 Farkas 引理或分离超平面证明。

与算法设计的联系

  • 最大流可以写成线性规划，最大流最小割定理是 LP 对偶的一个整数特例。
  • 顶点覆盖、集合覆盖、设施选址的 LP 松弛给出下界，再通过舍入得到近似算法。
  • 原始-对偶算法在近似算法与在线算法中反复出现：对偶变量可以解释为“价格”。

常见误区：把“线性规划可解”误推成“整数规划也可解”。整数约束会破坏凸性；全幺模矩阵是少数能让 LP 顶点自动取整的结构。

TOPIC 03 · COMPUTATIONAL COMPLEXITY

NP 完全性与归约

L4

NP 完全性不是“没有算法”，而是“目前不知道有多项式算法，且一旦有一个，所有 NP 问题都会有多项式算法”。它的核心工具是多项式时间归约。

四个概念

  • P：可以在多项式时间内判定的问题。
  • NP：给定一个证书，可以在多项式时间内验证解是否正确的问题。
  • NP-hard：所有 NP 问题都能多项式归约到它；它本身不必在 NP 中。
  • NP-complete：既在 NP 中，又是 NP-hard。
L₁ ≤ₚ L₂ ：存在多项式时间 f，使 x ∈ L₁ ⇔ f(x) ∈ L₂

归约方向很容易写反：要证明问题 B 是 NP-hard，需要把已知 NP-hard 问题 A 归约到 B，而不是把 B 归约到 A。

Cook–Levin 与经典归约链

Cook–Levin 定理证明布尔可满足性 SAT 是 NP-complete：任意非确定性图灵机的计算历史都可以编码成一个布尔公式。随后有一整条经典链：

SAT ≤ₚ 3-SAT ≤ₚ Independent Set ≤ₚ Vertex Cover
3-SAT ≤ₚ Hamiltonian Cycle ≤ₚ TSP
3-SAT ≤ₚ 3-Coloring　　SAT ≤ₚ Clique

这些归约不只是“证明难”，还揭示了问题结构之间的转换：独立集与顶点覆盖在补图意义下等价，TSP 的判定版本从哈密顿回路加入边权后得到。3-SAT 是 NP-complete，但 2-SAT 在 P 中——把每个二元子句写成两条蕴含边，可满足性等价于不存在变量与它的否定处于同一个强连通分量。

如果问题带有结构化参数 k，参数化算法可以在 f(k)·poly(n) 的时间内求解。例如顶点覆盖存在 O(2^k·n) 的搜索树算法；这并不与 NP-hard 冲突，因为 k 在输入中可能很小。

常见误区：“NP-hard 就一定不能在现实中求解”。很多 NP-hard 问题在实践中可通过分支限界、SAT 求解器、参数化算法、近似算法或 ILP 求解器处理；“NP-hard”描述的是最坏情况下的多项式时间可解性，而不是所有实例的难度。

  2. 为什么 TSP 的判定版本是 NP-complete，而欧几里得 TSP 仍有 PTAS？
  3. 如果一个问题是 NP-hard 且也在 NP 中，它是什么？P = NP 会带来什么后果？

TOPIC 04 · NEAR-OPTIMALITY

近似算法

L4

当精确解太难，我们仍希望给出一个可证明“离最优不远”的解。近似算法把 NP-hard 问题变成有性能保证的多项式时间算法。

近似比

对最小化问题，算法 A 的近似比为 ρ，若对所有实例都有 cost(A) ≤ ρ · OPT；最大化问题则要求 ALG ≥ OPT / ρ。ρ 越接近 1 越好。PTAS 表示对任意 ε > 0 都能在多项式时间（关于 n）内达到 1 + ε；FPTAS 还要求关于 1/ε 多项式。

LPT：按处理时间降序放置到当前负载最小的机器
makespan(LPT) ≤ (4/3 − 1/(3m)) · OPT

两个经典结果

多机调度 LPT：设最后一台完成的机器上最后放的是作业 j，其处理时间为 pⱼ。在放置 j 之前，它被放到了负载最小的机器，所以该机器此前的负载不超过平均负载；结合 pⱼ ≤ OPT，可推出 makespan ≤ (4/3 − 1/(3m)) OPT。这个界是紧的。

顶点覆盖 2-近似：取一个极大匹配 M，把 M 中每条边的两个端点都放入覆盖。任何顶点覆盖至少要包含 M 中每条边的一个端点，因此 |M| ≤ OPT，而算法大小为 2|M|，所以不超过 2·OPT。这个简单算法也说明：近似比常常来自一个清晰的结构下界。

集合覆盖贪心：每步选择覆盖最多未覆盖元素的集合，近似比为调和级数 H_n = 1 + 1/2 + … + 1/n ≤ ln n + 1。若不做任何复杂度假设，这个量级已经接近最优；Feige 的结果表明 (1−ε)ln n 的改进会推出 NP 的准多项式算法。任意顺序的列表调度只能保证 2 − 1/m，按 LPT 排序后才得到约 4/3 的界。

不可近似性：PCP 定理表明许多问题不存在任意接近 1 的多项式近似（除非 P = NP）；一般度量 TSP 没有常数因子近似，而欧氏 TSP 反而有 PTAS。近似算法的边界与问题版本、度量假设和复杂性理论紧密相连。

常见误区：把近似比的方向写反（最小化看 ALG/OPT，最大化看 OPT/ALG）；把 PTAS 当成工程上一定快的算法；或者在未说明“一般图 / 欧氏 / 度量”版本时讨论 TSP 的可近似性。

TOPIC 05 · RANDOMNESS

随机算法

L4

随机性不是“碰运气”，而是一种可分析的计算资源：它可以让算法更简单、更快，或者让最坏情况不再由对手精确控制。

两种正确性

  • Las Vegas：结果总是正确，运行时间或比较次数是随机变量；随机快排是典型例子。
  • Monte Carlo：运行时间有界，但可能以很小概率出错；通过独立重复可以指数级降低错误概率。

常见的复杂度类包括 RP（单边错误）、BPP（双边有界错误）与 ZPP = RP ∩ coRP（零错误、期望多项式时间）。它们帮助我们把“随机算法有多可靠”说清楚，而不是只凭一次运行的观感。

随机快排的期望比较次数不超过 2n ln n + O(n)，仍然是 O(n log n)。把每次 pivot 选择看成随机，递归树每一层期望只做线性工作。Karger 的最小割算法随机收缩边：固定一个最小割，它在一次运行中不被破坏的概率至少是 2/(n(n−1))；独立重复 O(n² log(1/δ)) 次，即可把失败概率降到 δ 以下。更精细地，随机快选只需期望 O(n) 时间，Schwartz–Zippel 引理则用有限域上的随机取值来做多项式恒等测试。

Pr[算法失败] ≤ δ ⇒ 重复 k 次后失败概率 ≤ δᵏ
Chernoff：Pr[X ≥ (1+δ)μ] ≤ exp(−δ²μ/3)

分析工具箱

期望的线性性、Markov / Chebyshev / Chernoff 界、条件期望与鞅，是随机算法分析的基本工具。随机化也可以用于打破对称性、做负载均衡、设计哈希与抽样。一个自然的问题是：随机性是否可以被消除？条件期望法（method of conditional expectations）与伪随机生成器给出了部分去随机化路径。

常见误区：“随机算法一定比确定性算法快”。随机化通常改善的是期望时间、最坏输入下的稳健性或实现简洁性；它也可能带来额外的失败概率与可重复性问题。

TOPIC 06 · UNCERTAINTY

在线算法与竞争比

L4

在线算法在不知道未来输入的情况下必须立刻决策。竞争比衡量它相对于“事后知道全部输入的最优离线算法”能差多少。

竞争比

对最小化问题，确定性在线算法 A 的竞争比为 ρ，若对所有输入序列都有 cost(A) ≤ ρ · OPT + O(1)；ρ 越接近 1 越好。随机在线算法通常用期望成本定义竞争比。

Ski Rental：每次租金 1，购买价 B
确定性策略：前 B−1 次租，之后购买 ⇒ 竞争比 2 − 1/B
随机策略的竞争比：e / (e − 1) ≈ 1.582
LRU：k-竞争　随机标记算法：2H_k ≤ 2 ln k + 2

经典模型

租雪橇问题：不知道会滑多少次。租到第 B 次再买，最坏情况下总成本约为最优的 2 倍；随机化策略把竞争比降到 e/(e−1)。

分页缓存：在线决定淘汰哪一页。Belady 最优算法需要未来信息；LRU 与 FIFO 都是 k-竞争，且任何确定性算法都不能优于 k。随机标记算法达到 2H_k，随机化下界为 H_k（Yao 原理）。列表更新中的 move-to-front 规则竞争比为 2，也是确定性最优。

在线算法的研究还包括：度量空间中的 k-server、在线匹配、在线集合覆盖、学习增强算法（learning-augmented algorithms）——当预测准确时追求更好的一致性，预测错误时仍保留鲁棒性。随机化在线算法还必须说明对手模型：oblivious adversary 与 adaptive adversary 会给出不同的下界。

常见误区：把竞争比当成平均性能；同一策略在真实分布上可能远好于最坏界。另一个误区是忽略“在线 / 流式”的区别：在线强调决策时序，流式强调空间限制，两者可以叠加但不是同一件事。

L4

先修算法与证明

研究难度与不确定性

建议顺序

  1. 先用本页最大流实验建立残量网络与割的直觉，再读 CLRS 第 26 章。
